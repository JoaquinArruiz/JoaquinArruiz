### ⭐ Featured project

<a href="https://github.com/JoaquinArruiz/Gutterberg">
  <img align="right" width="420" src="https://github-readme-stats.vercel.app/api/pin/?username=JoaquinArruiz&repo=Gutterberg&theme=tokyonight&hide_border=true" alt="Gutterberg"/>

- **[Gutterberg](https://github.com/JoaquinArruiz/Gutterberg)**: a desktop app that turns print-and-play PDFs and card scans into cut-ready print sheets, at exact card sizes, with the original vector artwork untouched.
  - 🦀 Rust PDF engine (lopdf, PDFium) + ⚛️ React 19 / TypeScript UI on **Tauri 2**
  - 🔍 Automatic piece detection, plus an optional AI mode (Anthropic, OpenAI-compatible, Gemini, Ollama)
  - 📦 Windows, macOS and Linux installers built by GitHub Actions, with in-app auto-updates
  - 🌐 English & Spanish
